- **Two code changes, declared here because they touch a gate:**
  1. **`--no-band`.** At 4B every band layer is banked, so the runner would re-run the already-published L2–13 β = 0.35 set on every one of the six invocations. `--no-band` restricts an invocation to its primary set. Pure cost control; no rule changes, and the 4B L7 defaults still reproduce when the flag is absent.
  2. **The identity gate is STRENGTHENED, not relaxed.** `identity()` computes `passes = all(v <= IDENT_TOL for v in gated.values())`, and `all({})` is **True** — so a layer whose banked rows lacked `dG_S_{edit,foreign,swap}_L{K}` would have **vacuously passed**. A multi-layer sweep is exactly where that could fire. Fixed by requiring all three banked-byte arms to be *present* (`missing_gated` reported, `passes` False otherwise). No threshold moves; this can only turn a pass into a failure, and it is being written **before** any H-E8 data exists.
