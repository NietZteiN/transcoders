- **Hypothesis (as the charter states it, and as I set out to confirm):** L3 is "stacked (all at once
  — **the decisive test, where the two routes compete for one budget**)". Under the project's own
  definitions the two routes are the **atom** route, whose adversarial form is L1b (decoy names that
  inject plausible-but-wrong semantics), and the **relational** route, L2 (dispatcher indirection).
  So L3 should contain L1b's decoy identifiers *and* L2's dispatcher. **Prediction: the identifiers
  L1b introduces appear in L3.**

- **Setup.** Read-only over `data/stimuli/dataset_{a,b}_source.json` (the tiers arrive
  pre-generated; the obfuscation pipeline itself is `allocation_replication/pipeline/obfuscation/`,
  which **did not travel to juno** and is not on this host). For each item carrying all of
  L0/L1/L1b/L3 — **20 in Dataset A, 50 in Dataset B** — tokenise identifiers with
  `[A-Za-z_$][A-Za-z_$0-9]*` minus a language-keyword stoplist, form the sets each tier *introduces*
  relative to L0, and measure what fraction survives into L3. Deterministic, no seed, no model.

- **Results.**

  | identifiers introduced by | mean fraction present in L3 | items with ≥ 1 present |
  |---|---|---|
  | **L1b** (the decoys) | **0.0000** | **0 / 70** |
  | **L1** (nonsense) | **1.0000** | **70 / 70** |

  Both datasets separately: A 0/20 and 20/20; B 0/50 and 50/50. The flagship item
  `JavaScript/63` makes it visible without statistics —

  - L0: `const fibfib = (n) => {`
  - L1: `const fibfib = a => {` (params mangled, function name kept)
  - L1b: `const smoothArea = (_lastNSecs) => {` (the decoy)
  - **L3: `const fibfib = a => { const b = { 'uepoi': function (c, d) {`** — L1's `a`, L0's
    `fibfib`, plus the dispatcher table. `smoothArea` never appears.

  Corroborating, from `src/convert_stimuli.py:121`: the converter derives L3's rename map by pairing
  **`("L2","L3")`**, never `("L1b","L3")`.

- **Hypothesis verdict: ✗ REFUTED, and the charter's framing with it.** **L3 = L1 ∘ L2**
  (nonsense renaming + flattening), **not L1b ∘ L2**. The stacked tier does not put the adversarial
  atom route and the relational route in competition, because the adversarial route is not in it.

- **Observations / consequences.**
  1. **The decisive test named in the charter does not exist in this corpus.** Every statement of the
     form "L3 is where the two routes compete for one budget" — in `CLAUDE.md` §3, in the proposal
     deck's framing, and by inheritance in any write-up — is not supported by the stimuli. What L3
     licenses is "nonsense renaming stacked on flattening", which is a real and interesting tier, but
     a different one. HT3's "breaks at L3" prediction (E3) needs re-reading in that light before E3
     is designed, not after.
  2. **1,327 L3 spans are mislabelled `adversarial`.** `convert_stimuli.py:133` calls a renamed span
     `l1_neutral` iff it matches `^(?:var|func|fn|v|f)_[0-9a-fA-F]{2,8}$`, else `adversarial`. Python
     L3's `var_68f8` matches and is labelled correctly; **JavaScript L3's mangled names (`a`, `b`,
     `uepoi`) do not**, so they fall through to `adversarial` on code that contains no decoy.
     Counts: Dataset A javascript 436; Dataset B javascript 891 (Python L3 is correctly split
     84/122 and 292/553). Any analysis keyed on the `adversarial` span class inherits this.
  3. **It explains a standing puzzle.** [`2026-08-31_ladder-replication-results.md`](2026-08-31_ladder-replication-results.md)
     asked "why is L3 weaker than L2?" (+0.0418 vs +0.1253) and offered the two-routes-compete
     reading as a candidate answer. That answer is now excluded: L3 contains no decoy, so it cannot
     be the atom route destroying the relational signal. The surviving explanations are the ones the
     entries already measured — L3's inflated code size raising its own baseline (+0.7893) and
     repetition becoming the binding predictor (+0.2531, driving Llama L3 to **−0.0845**).
  4. It also explains the sentinel pattern in
     [`2026-09-06_unpaired-sentinel-defect.md`](2026-09-06_unpaired-sentinel-defect.md) — L1 and L3
     fail together on JavaScript (97.3 % / 91.8 %) while L1b is perfect there (0.0 %) — because L1
     and L3 share the mangling that breaks equal-length positional pairing, and L1b does not.
