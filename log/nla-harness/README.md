## What worked
- **Changing exactly one thing, after the diagnosis pointed at it** (H-R7, 2026-09-15). The whole 16-arm bake-off was re-run through the paper's own `SteeredCausalLM` with a single substitution — `_build_prompt` wrapped in the model's chat template, ids gated equal to `apply_chat_template` — and it moved every arm +0.11…+0.23 while leaving their sampler, prior, parser and our seeds untouched. That is what made "their method is inert" a statement about the method rather than about a broken prompt, and it cost ~6 GPU-h.
- **An anchor that spans two independent harnesses.** `unsteered_chat` inside their runtime reproduced our own H-R1 runner to 0.000 (0.714 vs 0.714) on the same 50 programs, which retired the "maybe it's their top_k 7 sampler" explanation without a single extra run.
- **A control whose gate reads in both directions.** After the identity floor aborted for behaving correctly, the effect gate was made two-sided: the floor now FAILS if it changes any attention row. It then passed with 0/4 096 effective calls on all 50 snippets — which independently confirmed that the raw-prompt bake-off's accidental β = 0 arms really were the identity they were labelled as.
- **An automated invariant catching a defect in a banked result** — `arm_guard.paired` refused `R_2 − P_2` for mismatched position counts, and the refusal was correct: the ladder residual was a position-count effect (2026-09-07). Ten defects in the family; this was the first found by the harness rather than by a person.
- **Repairing the anchoring instead of restricting to the clean subset.** `repair_pairs.recover()` took the meaning contrast from 131 spans / 20 Python items to 471 spans / 60 items in both languages, and the effect replicated (+21.82 → +21.05).
- **Gating a family on whether the instrument can represent the positions at all.** Stage 0 cost 25 min and would have stopped everything for zero further GPU had it failed (2026-09-04).
- **Filing an interpretive floor MID-RUN, at 11/60, before any control mean existed** — on discovering that the frozen +12.11 support bar sat below the banked random benchmark of +19.60. Tightening a criterion before seeing the outcome is safe; loosening after is not (2026-09-04).
- **Re-expressing banked arms into a new unit instead of guessing.** The banked R2 arms converted exactly to `G_sum` from rows already on disk, giving the benchmarks (+19.60 random, +27.53 prompting) that every W claim is now judged against — no new compute.
- **Asking whether the instrument can represent the positions BEFORE trying to steer them.** Stage 0 cost 25 min and would have stopped the whole family for zero further GPU had it failed; instead it licensed stage 1 on a measured basis rather than an assumption (2026-09-04).
- **A tidiness counter caught a real defect.** `n_no_tags` was added so a run could report tag-less reads; it revealed that **22/22** smoke reads were truncated because `MAX_NEW_READ` was 96 under a comment falsely claiming it matched the project's 180. The vendored client only prints a warning, which scrolls past unread in a 400-read run.
- **Spending one CPU analysis to kill an expensive build.** The length-matched corpus fork was the obvious next move after the T diagnosis; a frozen-rule correlation on banked data (Experiment L) showed inflation does no independent work and retired it before anyone built stimuli. Decide corpus forks with data, not with plausibility (2026-09-03).
- **Doing the arithmetic on a 'cheap' experiment before running it.** H-T5 looked worth running because it was cheap; ~12 % of identifier tokens are alignable, so it returns a null by construction. Cheap is not the same as worth running.
- **Staging an expensive veto behind a cheap one.** R2's GPU specificity pass was declared but gated on an arm first clearing support + separation + the free behavioural veto. Nothing cleared, so the verdict landed for **zero GPU-hours** — and the pre-registration says in advance that not running it is the correct outcome, not a gap (2026-09-03 R2).
- **Naming the tie-break before scoring.** The prereg predicted R2-NULL-or-GENERIC and stated the exact condition separating them ("P_prompt clears iff mean G < 0.69"). G came out 0.3071 and the branch resolved as written, which is worth more than either verdict alone.
- **Cheap sanity gates caught two of three stages before they cost anything.** T's `all @ L0` ≥ 0.80 smoke refused a 3,900-pass run on a broken alignment for the price of 3 items; R's 60/60 sanity + noop floor proved the readout well-formed so the confound could be localised to the metric's *definition* rather than its implementation. Decomposing ΔM into its clean and corrupt halves — CPU-only, from banked rows — is what turned three headline verdicts into one coherent negative (2026-09-03 R/S/T).
- G0 gate: Stage A exact replication (0/101 over tol) after two real fixes (transformers
  5.12 `return_dict`; missing `<|im_end|>` in the reply layout); Stage B round trip
  matches the reference (median |Δcos| 0.0037), CJK 0-3/101.
- Code reads are theme-accurate out of the box; first DRM_AR signal moves the predicted
  direction (L1b −0.055 vs L0 −0.102 → decoy pulls ~+0.05).

- Pre-registration did its job: N5's early Δ=+0.0021 and the frozen |β|<0.005 refute clause
  meant HT12's negative result required no renegotiation after the numbers landed.

## What didn't
- **Ranking arms before checking the prompt** (2026-09-14/15). Three entries' worth of arm ordering — `role_proto` best non-oracle, `prompt_types` collapsed, `ridge_map` inert — was computed on a runtime whose raw prompt cost every arm +0.11…+0.23 accuracy and up to 0.23 of parse rate. Two of those three readings changed under the template. The lesson is cheap and general: **anchor the no-op arm against an independent harness before scoring any contrast**, which is exactly what the H-R1 comparison did once it was finally run.
- **Naming a control arm that only ever existed as a bug** (H-R7, jobs 403742/405553). `codesteer_beta0` came from the 2026-09-14 `beta_post` fault, so `--arm codesteer_beta0` was never a choice and the guard written *against* that fault refused β = 0 on sight; then the effect gate killed the arm for changing nothing, which is the arm's entire purpose. Two dead jobs for a control worth ~1.5 GPU-h. A control that is the identity needs its own gate direction from the start.
- **Three artifact verdicts in one day (2026-09-06) from arms that wrote nothing** — `T_L2_all` at zero positions scoring `W16-STRUCTURE-CARRIES-IT` from 45.71 − 0.00, and 29 structural zeros dragging a +21.82 gap to +8.91. Nothing distinguished "wrote nothing" from "did nothing" until `arm_guard`.
- **A frozen "≥ 2 of 5" corpus-bounded rule that missed a perfect language partition** because it counted properties instead of weighing them (2026-09-06). Left as fired; the sixth threshold to measure the wrong thing.
- **Two pre-registered operationalisations of the same hypothesis, both vacuous** (H-W2 trivially 1, H-W2′ trivially 0). The second survived a *written correction* because I reasoned about which **position** to read and never about which **layer** (2026-09-04).
- **Comparing a replacement arm against an additive benchmark.** Stage 1 read W1 ≈ "random" from a banked *additive* arm at α = 0.149; like-for-like random *replacement* is **−365.59** (2026-09-05).
- **Assuming a re-analysis is cheap without checking what is on disk.** H-W4 was filed as "no GPU"; no banked read corpus stores the vectors (2026-09-05).
- **Submitting without checking the dependency exists on this cluster.** Job 376102 FAILED in 40 s on `ModuleNotFoundError: No module named 'sglang'` — absent from all three juno envs, and the migration table never listed it. Fixed by *removing* the dependency (`local_av.py` runs the AV in-process, reusing the vendored injection path verbatim) rather than installing it.
- **Raw cosine on residual-stream vectors as a discriminator.** Everything sits near 0.97 by anisotropy; real differences are ~0.02 wide (2026-09-04).
- **Correlating anything item-level with a per-token metric without checking what it is coupled to.** G is ~1/reply-length (ρ = +0.889 with the reciprocal), so it manufactured one significant predictor and hid a real one, and flipped the sign of Experiment L's headline. **Four of the day's wrong headlines were measurement definitions, not science** (2026-09-03).
- **Assuming a smoke-gate near-miss is a bug to be fixed.** T's `all @ L0` = 0.784 vs 0.80 looked like an off-by-a-little alignment defect; measuring it showed **0/60 items can ever align 1:1**. The gate was right and the corpus is wrong. Diagnose before patching — and never tune a frozen threshold down to meet the data (2026-09-03).
- **Reading a null as "the write was too weak." Retired 2026-09-03.** On the damage-controlled readout the belief arms are *negative* and grow more negative with α (V1: −0.030 at α=1, −0.133 at α=4). Too-weak predicts ≈ 0; this is a write that costs the model likelihood on its own correct answer.
- **A likelihood-ratio metric whose denominator is the model's own greedy corrupt reply.** It is monotone in damage: crushing the corrupt trace raises it without any belief moving. This retro-explains why banked α=8 arms looked dramatic on continuous readouts while rescuing **0** items on accuracy. Any LLR-style rescue proxy built this way inherits the confound (2026-09-03 R/S/T).
- **Verdict logic that computes a control but doesn't gate on it.** S measured L0-specificity and greedy accuracy, printed catastrophic values for both, and still returned `S-LIVE` because the rule keyed only on held-out ΔM + shuffle. Gate on the veto, not beside it.

- **2026-09-03 — "across a 16× α range" overstates B4's coverage.** Delivered perturbation spans only **1.63×** over that α range (Gemma L32, n = 12), because the residual path saturates. B4's null stands; its *scope* does not extend as far as the coefficient range suggests. Any restatement should quote delivered r, not α. The Qwen measurement that would settle the transfer **cannot be made** under the model constraint.
- **Widening the injection channel does not rescue steering — it destroys generation.** P0.2's
  `all_reply` write drove parse rates to 0.100 (V1) / 0.283 (V3) / 0.383 (V4) from ~0.90 at
  `last_prompt`. Accuracy at `all_reply` is confounded with parseability and must not be quoted as
  a clean accuracy: most of the drop is unparseable output scored wrong. The verdict does not
  depend on separating the two, but the *magnitude* is not interpretable as comprehension damage.
- **Perfect information buys nothing through a too-wide channel.** At `all_reply`, V4 — which has
  seen the clean program — is indistinguishable from V3 and no better than V1, and all three do
  **more** damage than a random direction (−0.42/−0.50 vs −0.183).
- **A five-transform family average flipped sign between seeds** (`2026-08-26_e5b-seed-instability.md`):
  B0's headline contrast **+7.02 [+2.00, +10.09]** rested on the untested four being negative; at
  seed 2000 they are positive (family −1.24 → **+4.46**, four of five transforms flip). The
  published CI described sampling *within* one draw, not variability across draws. Only
  `arith_rewriting` survives (−8.22, −5.65).
- **`reset()` that rewinds a cursor without uninstalling the spec is a trap**
  (`2026-08-17_compose-port-validated.md`): the "clean" reference pass was itself still steered, so
  the hook appeared to write two positions instead of one. **The defect was in the test, not the
  hook** — the project's standing lesson, hit again.
- **V2 was silently broken until the sweep**: its decoy→true pairing zipped two identifier lists
  that differ in length on 52 of 60 pairs, so only **8** directions were being built. Had it not
  been caught, the one interesting cell in the sweep would have been reported on 8 items.
- SGLang server needs `ninja` (flashinfer JIT) — not in the env spec; installed ad hoc,
  add to `nla/environment.yml` on next edit.
- Digit-piece tokens (`state_1395` → `1`,`3`,`9`,`5`) verbalize as numerology — exclude
  sub-word digit positions from any quantitative read set.
- **All three confirmatory hypotheses failed — each by a named mechanism, not by weak data.**
  HT12 = reply length; HT14 = answer-string commonness; HT13 = unmeasurable per-item score.
- **A judge that separates populations need not rank items.** Llama's real-vs-shuffled AUC of 0.757
  looked like a working instrument; κ 0.05 vs a second rater and ρ 0.03 vs the AR baseline say it
  cannot rank single reads. Ship an AUC as evidence of a *sort key* only after an item-level
  reliability check.
- **A null must be attached to the statistic that carries the verdict.** HT14's foreign-answer null
  guarded the descriptive trajectory while the log-rank — the actual decision rule — ran unguarded,
  which is why a confounded p=0.002 initially looked like support.
- **The most trustworthy measurement in the programme needed no model.** N7 spent two GPUs and 5,653
  judged comparisons on a score that cannot rank one item; a regex against a known ground-truth field
  labelled all 9,511 readings for free. Look for a mechanically checkable claim *inside* the output
  before reaching for a judge.
- **A palette validator and a structure check both pass on a chart that is unreadable.** Neither
  looks at layout. The first render of the six figures had colliding labels, no ROC tick marks, a
  clipped line and white-on-dark text that was silently overridden — every automated check green.
  Rendering to an image and looking is the only step that catches it.
- **When a test contradicts a fix, suspect the test.** Two harness bugs during the artifact work
  each produced a confidently wrong conclusion; measuring the property that matters (*where does the
  highlight land*) rather than a proxy (*is the index present*) is what settled it.
- **A κ gate needs a companion discrimination check.** G3 failed because the second rater was
  *degenerate* (91% one label), not because two competent raters disagreed — a distinction κ alone
  does not surface.
- **The 2026-08-06 faithfulness↔correctness gap was a length confound** — read-level bootstrap
  without case clustering or a length control, exactly the two caveats logged at the time.
- **`(1|case)` is unusable for a predictor that is constant within case** (`correct` is: 0/330
  and 0/182 groups vary). It returned a singular fit on one corpus and β=0/NaN-se on the other.
  Use GEE (cluster=case) or a case-level model. **Frozen rules still need their estimator
  checked against the data's group structure *before* freezing.**
- Precise per-case error localization remains unsolved (D2-state vs D3 agree 39%; D3 self-agrees
  46%) — N5 works around it with a fixed 0.70–0.90 strip, not per-case bursts.

## Open ideas
- **H-R12 (no GPU first):** the H-R7 verdicts are all provisional because the damage CI includes 0 (+0.058 [−0.019, +0.140]). Compute, from these 50 snippets' bootstrap distribution, the corpus size that could certify a +0.05 steering effect (first estimate ≈ 150–200 snippets) and pre-register the smallest effect the extended corpus could detect **before** extending it. Power is now the binding constraint, not method.
- **H-R13 (~1.5 GPU-h):** `ridge_map` is the only arm whose point estimate never goes the wrong way (+0.046 chat, +0.025 over `erasure` raw) and its held-out cos is prompt-form-invariant (0.3791 vs 0.38). Re-run it at a fresh sampling seed: `RIDGE-REAL` if Δ vs `unsteered` stays ≥ +0.03, `RIDGE-NOISE` otherwise.
- **H-E4 (~0.1 GPU-h):** measure the **bf16 write-chaos floor** — write `swap` twice, once with banked `h0` bytes and once with `h0` perturbed by 1 bf16 ULP on the 111 components that differ — and publish it as a constant every future identity gate is specified against. Today's `E-HARNESS-FAULT` ([`2026-09-13_erasure-gate-fault.md`](2026-09-13_erasure-gate-fault.md)) shows the programme's standard 0.05-nat tolerance is only valid for **bit-identical** writes; any arithmetic-built arm (interpolations, projections, H-A7's length-matched controls) inherits a ~1-nat floor unrelated to the intervention.
- **H-S16 (~0.5 GPU-h, NOT free — cost corrected 2026-09-13):** regrade `edit_single`'s 7–10 parseable-but-wrong items against the **decoy** semantics. [`2026-09-13_parse-diagnostics.md`](2026-09-13_parse-diagnostics.md) called this free; it is not — `accuracy_rows.jsonl` stores only correct/parsed flags, **no generated text**, so the `edit_single` arm must be regenerated (60 items, greedy, one arm) with replies retained. If it returns the decoy's answer, full replacement installs a wrong belief rather than destroying the computation — the programme's originating question answered from the steering side.
- **H-A7 (~0.5 GPU-h):** length-matched L0 control (pad to the L2 token count with inert filler). Prompt length predicts parse rate **within item** (ρ = −0.305, p = 6.8 × 10⁻⁸), so length is a measured confound in Papers 2–3's behavioural tables too — a claim about the instrument, publishable either way.
- **H-S13 (~0.6 GPU-h):** L2 alone at β = 0.35, the one cell separating the `edit_single` accuracy harm (−0.121) into a β effect vs a layer effect. Currently confounded in both.
- **H-S14 (corpus):** ~270 screened items → ~30 flippable at the measured 11 % yield moves the perfect-rescue bound from p = 0.092 inside 0.05 — **the purchase the user's accuracy question actually turns on.**
- ~~Re-run the correct-vs-wrong faithfulness gap with case-level clustering + read-length control~~ — **done 2026-08-07, it does not survive** (HT12 refuted).
- Is `rt_cos` essentially a position/length meter rather than a comprehension meter? Predict correctness from reply length alone vs length + faithfulness — nearly free, and it would settle whether faithfulness adds anything at all.
- Untested by design: whether a real effect lives only among the 26 longest wrong cases that never found a length-compatible control (mostly L3). The matched analysis necessarily drops them.
- Un-park N1–N3 (HT9–HT11) — harness design done, gates G1–G3 specified in the plan file.
- Gloss anchors for DRM_AR are crude (absolute sign unreliable; relative differences are
  the signal) — refine gloss templates or use contrastive-activation anchors.
- Batch/async the AV client before any >1k-read run (sequential ≈ 1.5 s/read).
