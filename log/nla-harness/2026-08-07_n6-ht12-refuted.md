### Target Date: 2026-08-07 (N6 / HT12 — **REFUTED**: the faithfulness↔correctness gap is a length confound)

- **Hypotheses / what we're testing:** **HT12 (confirmatory)** — reconstruction faithfulness (`rt_cos`) predicts per-case correctness after controlling for tier, read kind, read length, reply length and relative position, with case-level clustering. Rule frozen in [`2026-08-06_n6-n8-preregistration.md`](2026-08-06_n6-n8-preregistration.md) **before** this ran: *confirm* = all three co-primaries (Wald p<.05, case-level permutation p<.05, cluster-bootstrap CI excludes 0); ***refute* = model CI includes 0 OR |β| < 0.005** ("too small to be a usable signal"). Run on both corpora separately, never pooled. Standing honesty clause from the pre-registration: the banked corpus is where the post-hoc finding was born, so N6 **sharpens** it there and **cannot independently confirm** it — the **dense corpus is the replication that decides**.

- **Setup:** `src/analysis/n6_faithfulness_mixed.py` (+ exploratory `src/analysis/n6_decomposition.py`), env `transcoders-mi` (statsmodels 0.14.6), **CPU only, no GPU**. Seed 20260724, `N_PERM=10000`, `N_BOOT=4000`, `REFUTE_BETA=0.005`. Inputs: `data/nla/overnight/2026-08-04/enriched.json` (banked, 2,828 reads with a defined `u_rel` / 330 cases) and `data/nla/n5/2026-08-06/dense_reads.jsonl` (dense, 4,653 reads / 182 cases). Outputs `data/nla/n6/2026-08-07/{ht12,ht12_decomposition}.json`.
  - **⚠ PRE-REGISTRATION DEVIATION (declared, not silent).** The frozen rule specified `MixedLM` with `(1|case)`. **That model is structurally unusable for this predictor** and I did not discover it until it failed: `correct` is **constant within every case** (verified **0/330** banked and **0/182** dense groups vary — a case is wholly right or wholly wrong), so a per-case random intercept absorbs exactly the between-case variance `correct` lives in. It returned a **singular fit** on banked and **β = 0.0 with NaN se** on dense. Replaced with **GEE, exchangeable working correlation, clustered on case** — the standard tool for a group-constant predictor: read-level data, clustering honoured, between-group effect estimable. The fixed-effect design was verified **full rank** in both corpora first, so this is a random-effects specification error, not collinearity. **Co-primaries (2) and (3) are untouched** — they were always case-level, and they carry the verdict. Deviation is recorded in-code at `n6_faithfulness_mixed.py:87-94`.

  **Both refute triggers fire on the replication**: the CI includes 0 *and* |β| = 0.0002 ≪ 0.005.

  - **This is an *informative* null, not an underpowered one.** The dense bootstrap upper bound (**+0.0081**) sits **below the banked raw difference (+0.0145)**, and the GEE CI upper bound (+0.0047) sits below the banked β (+0.0077). The matched sample does not merely fail to find the effect — it **statistically excludes an effect of the banked size**.
  - **Decomposition (exploratory, no FDR)** — the dense corpus differs from banked in *two* ways (length-matched case selection; strip-weighted positions), so I attributed the collapse:

    **Restricting the *same banked reads* to the length-matched case set already kills it** — raw Δ falls 0.0145 → 0.0035 (4×) and p goes to 0.21, with no new reads and no position change. Removing the strip weighting (`dense/sweep-only`) does *not* revive it. **So the confound is case selection / reply length, not the dense run's position composition.**

- **What worked / hypothesis verdict:** **HT12 ✗ REFUTED.** Faithfulness does not usefully predict correctness once cases are length-matched. The 2026-08-04 post-hoc finding — "correct runs are more describable than wrong ones in every tier, all CIs excluding 0" — is **an artifact of reply length**: wrong traces run ~1.6× longer at the median, `rt_cos` declines with position/length, so length drove both sides of the correlation. Recorded as a **negative confirmatory result**, which is exactly what N5's design was built to be able to return.

- **Observations:**
  1. **The pre-registration worked, including its refute clause.** N5's raw Δ = +0.0021 flagged this a day early, the frozen |β| < 0.005 threshold was already sitting under it, and nothing had to be renegotiated after seeing the number. The one thing pre-registration did *not* protect against was a mis-specified model — worth noting that a frozen rule still needs its estimator sanity-checked against the data's group structure before it is frozen.
  2. **`(1|case)` is the wrong random effect for any case-level predictor.** HT13/HT14 must be re-checked for the same trap before they run: any predictor constant within case needs GEE or a case-level model, not a per-case random intercept. HT13's interaction term (`correct × after_error`) varies *within* case and is safe; **HT14's onset comparison is between-case and is NOT** — fix it before running N8.
  3. **Missingness is real and must be reported, not buried:** 26 of 117 wrong cases never found a length-compatible control (mostly L3 — fewest correct cases, longest traces). The matched analysis therefore also drops the most extreme wrong traces, so "length-balanced" and "extremes-removed" are **not separable** in this design. The honest statement is that the effect does not survive in the length-comparable region of the corpus; whether something real lives only among the very longest wrong traces is untested and would need a different design.
  4. The strip (the 0.70–0.90 trough where the verified errors sit) shows a **slightly negative** correct-vs-wrong Δ (−0.0012, CI spanning zero). No signal, but it does not support "faithfulness dips where the model errs" either — that exploratory question from N5 comes back **null so far**.
  5. BH-FDR is a family of three (HT12/13/14) and **has not been applied yet** — it gets applied once N7 and N8 report. HT12's refutation does not depend on it (a refute trigger fired, not a p-value).

- **New questions / new hypotheses:** (a) Is `rt_cos` essentially a *position/length* meter rather than a comprehension meter? A direct test — predict correctness from reply length alone vs length + faithfulness — would settle whether faithfulness adds anything at all, and is nearly free. (b) With the global faithfulness→correctness link dead, HT13's **localized** claim becomes the load-bearing one: does faithfulness drop *specifically after the error* relative to before, within the same trace? That is a within-case contrast and is immune to the length confound that killed HT12 — which makes N7 more important, not less.
