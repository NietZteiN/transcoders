- **Why this exists.** Two findings hours apart forced it. (1) **Greedy decoding is not reproducible on this host:** the same item, same prompt ids, same model, same budget, same job gave different generations in 3 of 6 cases, diverging at token 73 / 201 / 32, and one of them flipped `l1b_correct` from False to True (`hexc/JavaScript/93`). The `reverse` cell (L1b correct where L0 is wrong) is the tell: adversarial renaming cannot plausibly *improve* comprehension, so those items are measurement noise, and by symmetry most of the "flippable" set is too. **The 7-item flippable subset that the entire accuracy arm rests on is the positive tail of churn, not a set of decoy-damaged items.**
- **What this retracts (correction to my own entry, per CLAUDE.md §6, in a new dated entry).** [`2026-09-13_budget-confound-results.md`](2026-09-13_budget-confound-results.md) concluded that steering "does not add correctness — it relocates it, toward exactly the items the trap damaged." The `RESCUE-REAL` rule frozen in [`2026-09-13_bigger-corpus-prereg.md`](2026-09-13_bigger-corpus-prereg.md) is therefore **suspended before seeing its data** — testing a rescue of noise-selected items is not a test — and H-S14b does not run in that form.
- **Hypotheses:**
  - **H-A13 (the noise floor).** Re-run the `dataset_c` screen a second time under the **identical command** (same seed, same budget, same loader, same host, no intervention of any kind) and count per-item label changes. Statistic: the **discordant rate** `n(run1≠run2) / n` separately for L0 and L1b, plus the full 2×2 per tier.
    - **`CHURN-DOMINATES`** if the L1b discordant rate is **≥ the flippable rate** measured in the screen → the flippable set cannot be distinguished from noise, and no rescue test on it is interpretable. Every accuracy verdict in this programme is then bounded below by this floor and must be restated with it.
    - **`CHURN-SUBDOMINANT`** if the discordant rate is **< half** the flippable rate → a real decoy signal exists above the noise and H-S14b can be re-specified on items that are flippable in **both** runs.
    - **`CHURN-INTERMEDIATE`** otherwise → report the floor, and any subsequent flippable set requires agreement across ≥ 2 independent runs by construction.
  - **H-A13b (descriptive, free from the same data):** does divergence track reply length? The three observed divergences were at tokens 32, 73 and 201 of replies of 612–1178 tokens, while the one item that reproduced exactly had the **shortest** reply (287). If long replies churn more, every long-reasoning item in this corpus is noisier than every short one, which is a bias with a direction — against exactly the hard items the study is about.
  - **Prediction, recorded now:** **`CHURN-DOMINATES`**. The reverse cells (5/60 banked, 3/57 here) already put the floor at ~5–8 %, against flippable rates of 11.7 % and 7.0 %. I expect the L1b discordant rate near 8–15 % and the honest conclusion to be that **this host cannot measure a per-item decoy effect of the size this corpus contains.** Stated at moderate confidence: my record today is 3 of 8.
